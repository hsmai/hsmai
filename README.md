`LLM 서비스` · `검증 파이프라인` · `코딩 에이전트 워크플로우`

주요 관심 분야는 LLM, 멀티모달 LLM, 컴퓨터 비전이며, 그중에서도 믿고 맡길 수 있는 멀티모달 LLM 에이전트에 관심이 많습니다. 이론을 실제 문제를 푸는 시스템으로 옮겨, 일상을 더 낫게 만드는 AI 기술을 만드는 일을 좋아합니다. 이 역량을 키우기 위해 대회와 프로젝트에 적극적으로 참여하며, 수업에서 배운 것을 현실의 과제에 적용해 왔습니다.

대표적인 성과는 2025 SW중심대학 디지털 경진대회 대상(과학기술정보통신부장관상)입니다. LLM 기반 접근을 실제 문제에 적용해, 학습 데이터에 없던 새로운 글에서도 성능이 유지되는 판별 모델로 1위를 했습니다. 캡스톤디자인에서는 유튜브 리뷰 영상의 자막과 댓글로 구매 판단 보고서를 써 주는 LLM 서비스를 만들어 배포했고, 우수상을 받았습니다.

만드는 데서 끝내지 않고, 실제 환경에서도 믿고 쓸 수 있는지까지 확인합니다. 궁금한 점이 있다면 언제든 편하게 연락 주세요!
